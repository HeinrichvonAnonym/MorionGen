# K v1 冻结与验证记录

原始逐记录结果及大体积产物在冻结文件记载的数据盘路径。汇总中的中位数/P95 在原记录层面汇总；Han 段先归并到原记录，人员等权结果另列。格式验证窗及光学一致性参考的适用范围见 K 模块 README 和阶段报告。
