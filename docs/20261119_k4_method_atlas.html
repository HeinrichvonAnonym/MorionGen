从分歧机制理解备选方案

几何可达性，与域内求解分开

中心注册、躯干代理、固定足端和坐标域改变可表达的姿态集合。多初值与反向遍历改变域内搜索路径。前者若存在表示不足，后者再充分也无法消除模型残差。

目标、前态和整段耦合是三种变化

骨盆强调重分配损失；率超额约束拟合新增速度；反向遍历改变前态递推；整段GN把相邻误差联合求解。它们不应被统称为“连续性优化”。

导出变体提供更干净的配对

协调导出固定同一原生解，改变采样间FK路径。E0/EL→EA的比较可以定位导出因素；几何、域和目标同时改变的两行比较，需要进一步单因素消融才能归因。

已有组合是受输入契约约束的设计点。 这张图不建议将所有维度任意组合。例如声明中心依赖rig；位置链长策略受可辨识性和稳定性门控；等价坐标图在当前方案中用于整段求解前；导出协调不增加观测资格。

运行时候选选择只读D。独立评分对每个适用候选分别报告D−R、F−D、F−R，保留原始/统一骨长与原生/导出时钟。候选自身通过率、互补覆盖和选择器命中率分别记录。

这套结构中，哪里可以加速或Batch？

计算边界可以保持算法的并行已有实现 / 证据剩余工程
同一θ、同一次迭代FK的多帧和有限差分扰动列Torch批FK、扰动批、模型驻留、CUDA Graph已接入完整r/J与接受决策尚未全部设备驻留
相互独立的候选 / 序列各自保持前态，按就绪请求合批CPU独立候选调度；相同模型跨序列仅有局部实验异构θ的批FK、动态活跃样本和设备端TRF控制
整段GN给定Q后全帧特征/导数；独立轨迹系统批模型计算与CPU稀疏算子局部优化有界线性子问题及稀疏结构的等价GPU实现
原生解 → 导出变体复用原生拟合；独立区间/路径的模型评价固定锚点、支持门控、原生结果复用协调路径GPU批求解；现有前态初始化不能直接删除
固定几何 / 基础IK独立模型/初值；哈希一致时复用CPU校准、基础IK与回退、模型导出基础IK和足端SLSQP没有完整GPU一致性路径
头颈 / root / 独立验收身体姿态确定后的多帧计算与批评分CPU完整语义；Torch批评分后端已有头颈/导出整条GPU覆盖与独立回读资格仍待完成

必须保持的是依赖关系，不是CPU位置。单序列的连续前态与一次迭代的接受步骤有逻辑顺序，但可在设备上控制。删初值、删目标、换求解器或把耦合帧拆开属于算法变化，需独立验收。

本页解释方法结构与工程覆盖，不将局部加速解释为所有分支已替换CPU。当前CPU/GPU实测进展见独立诊断报告。
