4. 剩余瓶颈：077 ARDy的原生时序

唯一零通过路线为077 ARDy，来自MasticCultivation的S02擦拭记录（Wiping），窗口0–3.0778 s。两种选择器均选rig_reverse_rate_leg_path__coordinated。它的姿态、位置及覆盖通过，D时钟下骨盆连线方向变化率误差P95为10.065547°/s，D−R基线为0.000996°/s，新增量10.064551°/s，超过冻结10°/s门槛约0.064551°/s。原生与导出都保留该失败，R时钟则通过：这是采样时钟相关的残余原生时序问题；协调导出没有消除它。候选池中没有通过方案，选择器没有漏选。

失败候选的主要问题集中在肩、躯干及下肢时序。去除320个别名单元后，1179个独立候选单元失败：619仅姿态、328仅时序、232两者兼有。1119在原生结果已失败，60仅在导出验收失败。协调导出的成对对照挽回60个候选单元，未出现“原通过、协调后失败”；这支持它修复采样点之间路径，但原生拟合仍是失败的主要来源。上述计数是重复候选实验单元，不能当作1179个独立动作样本。

因此，下一步应单独诊断077骨盆方向的原生时间差分与连续分支，保留D/R时钟配对；本次分析没有修改求解方法或验收规则。协调导出的改善证据来自成对对照；不同完整候选的胜负只能说明策略互补，无法单凭通过率把效果归给某一个内部组件。
